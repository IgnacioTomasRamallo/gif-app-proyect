# GIF Expert

Buscador de GIFs desarrollado con React y Vite. Incluye historial de búsquedas
persistente en el navegador, selección rápida de consultas anteriores y diseño
responsive.

## Desarrollo local

1. Copiá `.env.example` como `.env` y configurá `VITE_GIPHY_API_KEY`.
2. Ejecutá `npm install`.
3. Iniciá la aplicación con `npm run dev`.

## Producción

La compilación se genera con `npm run build` en la carpeta `dist`. Para Vercel,
agregá `VITE_GIPHY_API_KEY` en las variables de entorno del proyecto.
